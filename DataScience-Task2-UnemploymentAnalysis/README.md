# Unemployment Analysis in India

## Project Overview
This project analyses unemployment trends in India using Python and data visualisation techniques. It explores state-wise unemployment rates, urban and rural differences, labour participation and changes during the COVID-19 period.

## Dataset
- Dataset: Unemployment in India
- Source: [GitHub Dataset](https://github.com/Apaulgithub/oibsip_taskno2)
- Information: State/region, date, unemployment rate, employment estimates, labour participation rate and area.

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
1. Dataset loading and exploration.
2. Data cleaning and preprocessing.
3. State-wise unemployment analysis.
4. Monthly unemployment trend analysis.
5. Urban vs Rural unemployment comparison.
6. Before and after COVID-19 lockdown comparison.
7. State-wise labour participation analysis.
8. Correlation heatmap.

## Visualisations
The project includes:
- State-wise unemployment bar chart.
- Monthly unemployment trend line chart.
- Urban vs Rural comparison chart.
- COVID-19 period comparison chart.
- Labour participation bar chart.
- Correlation heatmap.

## Key Findings
The analysis explores differences in unemployment rates across states, changes over time, urban and rural patterns, and relationships between employment-related indicators.
