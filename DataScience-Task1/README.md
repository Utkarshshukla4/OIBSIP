# Iris Flower Classification

## Project Overview
This project uses machine learning to classify Iris flowers into three species:
- Iris Setosa
- Iris Versicolor
- Iris Virginica

The project uses the famous Iris dataset provided by Scikit-learn.

## Objectives
- Explore and understand the Iris dataset.
- Perform Exploratory Data Analysis (EDA).
- Visualise relationships between flower features.
- Train and compare two classification algorithms.
- Evaluate model performance using classification metrics.

## Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Project Workflow
1. Load the Iris dataset.
2. Perform data exploration and preprocessing.
3. Create pairplots and boxplots.
4. Split the dataset into 80% training and 20% testing data.
5. Train Logistic Regression and K-Nearest Neighbors (KNN) models.
6. Evaluate both models using accuracy, precision, recall, F1-score and confusion matrices.
7. Compare the models and select the best-performing model.

## Project Files
- `Iris_Classification.ipynb` – Jupyter Notebook containing the complete analysis and model training.
- `best_iris_model.pkl` – Saved best-performing model.

## Conclusion
This project demonstrates how machine learning classification algorithms can identify Iris flower species using their measurements. It also compares two models to understand their performance.
